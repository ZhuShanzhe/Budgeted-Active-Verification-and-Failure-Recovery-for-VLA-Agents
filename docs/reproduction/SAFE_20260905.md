# SAFE：真实机器人跨任务失败检测

## 已完成的实验

2026-09-05，在作者发布的 OpenVLA/WidowX 数据上完成 SAFE 官方 LSTM、MLP（`indep`）实现各 3 个随机种子的训练与独立复核。每次训练 1,000 epoch，保存最终权重，不根据未见任务测试分数选择 checkpoint。

这是**官方实现、固定配置的定量基线**，不是论文所有策略、数据集与超参数网格的完整复现。W&B 全程禁用，没有上传数据或实验结果。

| 未见任务指标，均值 ± 样本标准差 | LSTM | MLP |
|---|---:|---:|
| 最大报警分数 AUROC（early-stop 口径） | 0.6278 ± 0.0099 | 0.8185 ± 0.0367 |
| 最大报警分数 AUPRC（early-stop 口径） | 0.7398 ± 0.0230 | 0.8734 ± 0.0384 |
| 官方评测窗口 50% 时刻 AUROC | 0.6319 ± 0.0261 | 0.6172 ± 0.0703 |
| 官方评测窗口 100% 时刻 AUROC | 0.6794 ± 0.0443 | 0.8185 ± 0.0367 |

失败为正类；AUPRC 使用官方 `auc(recall, precision)`，不等同于 average precision。early-stop 取 `scores[:task_min_step]` 的最大值；`task_min_step` 是该任务的最短轨迹长度。比例 q 的时刻分数取索引 `round((task_min_step - 1) * q)`，因此这里的 100% 是任务统一评测窗口末端，不是每条轨迹自己的终点。LSTM 的时刻分数与最大报警分数不同，不能混用。三次运行同时改变任务划分和训练随机性，标准差包含两者变化，不是固定测试集上的纯训练随机性。

当前固定配置中，MLP 在整个 early-stop 窗口的报警排序优于 LSTM；在窗口 50% 时刻并没有同样的优势。累计报警与及时发现失败是不同的评价目标，不能只保留单一汇总 AUROC。

## 数据与划分

- 原始 ZIP：`/root/autodl-tmp/datasets/safe-rollouts/openvla-widowx/openvla_widowx.zip`。
- 解压目录：`/root/autodl-tmp/datasets/safe-rollouts/widowx-extracted/openvla_widowx`。
- 532 条轨迹，8 个任务；每条配有 CSV、内部特征 PKL 和 MP4。
- 原始 ZIP 为 1,408,209,350 字节；SHA-256 为 `4106807a7e9e70ca0b11757d56029c1cd06c57aa95199443de62d366fdece912`，CRC 检查通过。
- 沿用官方 `unseen_task_ratio=0.25`、`seen_train_ratio=0.66`；种子为 0、1、2。
- 每次保留 2 个未见任务。训练和测试没有相同轨迹路径；训练任务与未见任务集合不相交，已程序检查。
- 使用策略内部 token 特征均值，4096 维；不是仅靠外部 RGB 的黑盒 critic。后续对照必须明确输入权限和特征提取成本。

精确轨迹名单、任务 ID 和成功/失败数量存于每次运行的 `splits.json`。`val_seen` 用于官方校准，`val_unseen` 用于跨任务测试；没有将未见任务用于调参。

## 配置与复现入口

共同配置：batch size 64、学习率 1e-4、token 均值、不进行全数据特征标准化、1,000 epoch、每 250 epoch 计算中间指标。LSTM 的 `lambda_reg=0.001`，MLP 的 `lambda_reg=0.01`；其余结构及损失保持官方默认。这是预先固定的网格内配置，没有最优配置筛选。

```bash
bash scripts/run_safe_baseline_matrix.sh
OMP_NUM_THREADS=4 /root/autodl-tmp/conda-envs/vla-safe/bin/python scripts/eval_saved_safe.py
/root/autodl-tmp/conda-envs/vla-safe/bin/python scripts/collect_baseline_audit.py
```

兼容性处理仅涉及日志和设备接口：去除新版 W&B 不接受的 `finish(quiet=...)` 参数；使用 SAFE 自带 `.to("cuda")` 更新其内部设备记录。独立评测重新加载保存权重，并核对训练时的划分名单。没有修改 SAFE 结构、损失或官方评测函数。

在 `val_seen` 的成功轨迹上校准、alpha=0.10、未见任务窗口末端（`at earliest stop`）口径下，实测误报率如下。这里是单个末端时刻的分数，不是上表 AUROC 使用的窗口内最大值（`by earliest stop`）。

| 模型 | seed 0 | seed 1 | seed 2 |
|---|---:|---:|---:|
| LSTM | 4.84% | 27.87% | 38.71% |
| MLP | 53.23% | 1.64% | 14.52% |

这批结果体现出校准阈值跨任务迁移的不稳定性。较低误报率也不等于良好检测：LSTM seed 0 对应失败检出率仅 7.69%。原始阈值、TPR、FPR 和划分可在 `results/20260905/safe_conformal_alpha01.json` 中逐项复查。该观察是现有基线的实测现象，不是新方法已经解决的问题。

## 使用边界

这组数据属于 WidowX 真实机器人任务，不是 LIBERO 仿真数据；数值不能与 LIBERO 成功率或 WCM value RMSE 混为同一指标。本批实验没有训练主动证据路由、恢复策略或本项目的新模型。DROID 配额问题不影响本页已完成结果。
