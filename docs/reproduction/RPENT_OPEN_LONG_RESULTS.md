# RPent：公开感知替换后的长任务适配评测

原生 ApiAgentLoop、LIBERO Toolkit/Primitives、公开记忆与指令模板保留。SAM3 替换为 Grounding DINO-base + SAM2.1-large；冻结 LeRobot Pi0.5，DeepSeek V4-Pro 决策、Flash 图像转写。

本组使用高清 RGB-D、相机标定、直接机械控制与公开记忆，每次 VLA 重规划执行 5 步；上一组使用双路 RGB 与最长 32 步动作段。成绩不能直接视为同工具条件下 Agent 的优劣。

LIBERO-10 全部任务；初态索引 40、种子 7、物理上限 520；不自动按成功真值停止。每条上限 160 次 API 调用、120 轮规划、3 美元，并受批次剩余费用限制。每任务一条，是诊断性结果，不能估计稳定泛化成功率。

因果结论需要逐轨迹检查，不从低成功率直接推出记忆失效。优先区分目标身份与定位错误、动作能力边界、过期证据、局部完成与整体完成混淆、恢复循环及上下文/预算消耗。

## 已定位的长程问题

- **预算消耗而非单纯动作失败。** 6/10 条轨迹因费用预算停止，3/10 达物理步数上限，1/10 遇到决策输出长度上限。单条任务仍在进行时，读记忆、分割、反投影和重复查看状态已占用大量调用；不能把所有失败都归因于 VLA。
- **成功的时间稳定性。** 任务 5 的真值仅在第 327–328 步成立，第 329 步已失效。一次 `release` 后仍有物理运动和物体稳定过程。因此“曾经成功、最终失败”不能直接解释为 Agent 在稳定完成后错误地重启任务，也不能声称加一个立即停止判断就能解决。
- **未知值被误当作失败证据。** 任务 5 在第 332 步的决策声称“predicate hasn't fired”，但当前成功真值没有提供给它；部署提示已注明 `terminated=null` 表示未知。它结合图像转写、分割坐标和历史案例继续推断。这是日志中可确认的证据解释错误；它对最终失败的因果贡献尚未由消融验证。
- **历史经验的适用范围未自动解决。** 发布的任务记忆包含 `10_swap_*` 案例，而标准任务提示首先请求 `10_t*_s0`，出现可恢复的文件不存在错误；Agent 随后可列目录并读取已有案例。不能把跨布局参考坐标当作当前对象真值。此处同时存在记忆检索接口与跨场景迁移问题，不是纯粹的长上下文能力测量。
- **感知转写的不确定性未充分传递。** 任务 5 的后续推理明确注意到不同图像描述冲突，仍据此重复定位和抓取。需区分转写错误、掩码/点坐标歧义与规划错误；本实验不将它们统称为“遗忘”。

任务 5 累计决策输入 1,771,933 tokens，单次最高 59,221 tokens；有 14 次文本读取、9 次分割、10 次反投影、9 次直接移动、2 次 VLA 抓取。上述数字由原始调用账本与物理步日志提取，不含 Flash 的输入 tokens。

证据：服务器 `experiments/coding-agent/20260915-rpent-open-final-summary-v1/diagnostic-extract.txt`，原始轨迹位置见同目录 `summary.json`。结论仅针对当前模型、工具和预算的适配版本。
