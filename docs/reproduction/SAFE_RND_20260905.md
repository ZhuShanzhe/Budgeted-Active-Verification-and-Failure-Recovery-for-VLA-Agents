# SAFE RND：固定配置补充复现

## 完成范围与协议

WidowX、DROID 各 seed 0/1/2，六组全部完成 200 epoch、最终检查点保存、重新加载和全划分评测。使用 SAFE 官方 RND 网络与损失，数据筛选、轨迹路径和任务划分与已完成 LSTM 基线逐项相同。不在测试集上选择 checkpoint、训练轮数或参数。

配置：Adam、学习率 1e-4、weight_decay=0.01、dropout=0、成功和失败均参与、其余官方默认。名义 batch 32；尾批小于 16 时并入前一批。上游损失分别对成败类取均值，极小单类尾批会导致 NaN；该适配保留全部轨迹和原损失，非静默丢弃异常 batch。所有 1,200 条 epoch 日志损失均为有限值。

这是官方实现的固定配置补充，不是作者全参数网格或等预算最优复现。先执行的单 epoch 资源探测不纳入结果。

## 结果

未见任务，均值 ± 样本标准差；失败为正类，early 指统一窗口内最大风险分数，AUPRC 是曲线积分。

| 指标 | WidowX | DROID |
|---|---:|---:|
| early-stop AUROC | 0.4941 ± 0.0401 | 0.4887 ± 0.0196 |
| early-stop AUPRC | 0.5956 ± 0.0496 | 0.4938 ± 0.0098 |
| 50% 窗口时刻 AUROC | 0.5316 ± 0.0680 | 0.4975 ± 0.0183 |
| 100% 窗口时刻 AUROC | 0.5754 ± 0.0705 | 0.5955 ± 0.0324 |

成功轨迹校准、alpha=0.10、**窗口累计报警**（`by earliest stop`）下的未见任务结果：

| 域 / 种子 | FPR | TPR |
|---|---:|---:|
| WidowX / 0 | 0.0484 | 0.0288 |
| WidowX / 1 | 0.0000 | 0.0000 |
| WidowX / 2 | 0.0000 | 0.0115 |
| DROID / 0 | 0.0667 | 0.0556 |
| DROID / 1 | 0.0778 | 0.0556 |
| DROID / 2 | 0.0778 | 0.0556 |

同时导出了末端时刻（`at earliest stop`）校准结果，两种时间口径不可混用。该配置呈现低 FPR 和极低 TPR 并存，不能把“很少报警”写成可靠检测；OOD 下也不能将 alpha 直接当作误报保证。

## 独立复核与异常标签

- 每个最终检查点重新加载，首条 val_seen 轨迹与保存前分数对比差为 0；此后全划分预测都来自重新加载的权重。不是两次全量独立模型前向。
- DROID 三种子从保存的 NPZ 独立重算所有标量指标，最大差为 0。
- DROID 三组另从校准/未见测试中排除既有标签异常，保持原权重、预测和 task_min_step；训练集不改变。排除后的 early AUROC 为 0.4889 ± 0.0171，未改变当前配置下排序较弱的观察。这不是清洗重训，不能排除训练标签问题。
- 权重 SHA-256、精确 split、配置、全部训练日志及校准表已导出，小型证据不含原始视频、特征库或权重。

## 结论与复现入口

本轮补齐学习型 RND 对照；当前固定配置的未见任务累计排序较弱。不同模型的训练轮数与 batch 不同，不能宣称是等算力最优能力排名。保留负面结果，不根据已知测试成绩重新选择参数。
