# 机器人操作 Agent 长程能力：已完成的适配评测

2026-09-15。计划 30 条真实 LIBERO 仿真轨迹，有效完成 30 条；来源批次另有 1 条基础设施失败，排除后重跑。三组初态与稳定后状态、任务覆盖、实际模型输出上限和真值隔离核验通过。本报告记录当前部署的实测成绩，不代表原论文完整系统复现或总体排行榜。

## 方法与实际流程

使用原始 LIBERO `libero_10` 的全部 10 个 Long 任务，每任务仅一个公开初始状态（索引 40），种子 7。冻结同一 Pi0.5；两路 256×256 RGB、8D 自身状态、7D 动作，最长 32 步动作段，物理上限 520 步，预热 10 步不计入。没有真值成功自动停止。逐步目标真值仅由可信宿主离线评分，不供 Agent 决策。

| 系统 | 复现方法与流程 | 适配边界 |
|---|---|---|
| Fixed Pi0.5 | 完整任务指令 → 双相机及自身状态 → 固定策略动作段 → 执行到物理上限 | 不具备任务完成判断；因此同时记录曾经成功与停止时成功。 |
| EmbodiedSkills 适配 | 原生 AgentLoop/skills：观察 → 子任务计划 → 前置检查 → 有界动作 → 验证 → 继续/恢复；共享状态与阶段约束保留 | 官方 LIBERO/LeRobot 后端，换用 DeepSeek 上层；隐藏原接口的任务成功信号，不移植 SAM3。 |
| Thea port 适配 | 原生 Harness、Task Notes、上下文管理、ModelEvaluator；观察 → 子任务工具 → 独立验证 → 重试/继续/complete/abstain | Pi0.5 封装为技能，没有完整 Scene Graph、真机技能及跨任务经验库；不得省略名称中的 port 而充当论文整机成绩。 |

决策模型为 DeepSeek V4-Pro，图像先经 Flash 转写并标记来源；独立视觉验证器直接读取图像。思考模式关闭，temperature=0，不保证服务逐次完全一致。每条轨迹最多 120 个框架循环、160 次模型调用、160 次采集；决策/直接视觉/验证输出上限均 2048 token，图像转写 1536。单条费用上限最多 3 美元，并受批次剩余预算限制；有效轨迹均未触发费用上限。实际步数和调用次数不强行对齐，预算消耗本身是评测对象。

## 失效证据与本研究的改进入口

### 1. Fixed：缺失可信的完成检测与停止

9/10 曾达到目标，7/10 最终维持。任务 5、6 的真值序列包含成功后再次失败。这里的具体改进入口是证据驱动停止与已完成条件的持续保护，不是重新训练整套动作策略；本轮没有验证任何新方法已能解决。

### 2. EmbodiedSkills：目标身份/状态判定不一致，重复调度消耗预算

任务 0 的 8 段 VLA 指令均停留在抓取 alphabet soup can，阶段未越过 S1。第 96 步可见夹持罐体，第 128 步罐体移动到篮子上方；7 次已完成验证仍未确认抓取子目标。原图与实际 verifier 请求中的图像哈希匹配，排除旧图传输问题。图中存在多个包装干扰，不能仅凭“夹持了罐体”断言指定商品身份已被识别。

固定第 96 步当前图像、同一 Flash 模型，交替执行三种条件各 3 次：原上下文、删除历史黑板、增加第 32/64 步图像，命名目标的抓持判断均 0/3 肯定。再用中性问题“是否持有任意物体，不猜商品名称”，3/3 肯定且描述蓝黄色罐体。后者改变了问题，不是同一准确率指标。证据更支持任务名称与视觉实体对应困难，而不是直接证明历史遗忘；简单添加历史图像没有在该检查点修复判断。

10 条轨迹全部先耗尽模型调用预算。对应研发对象是可追踪的目标身份、子目标完成证据、低收益重试抑制及调度成本，而不是把更多上下文直接视为解决方案。

### 3. Thea port：复合目标漏检与不可见状态解释

任务 2 在第 225 步 complete：离线按记录动作逐步回放，炉灶开启首次成立于第 86 步，但摩卡壶在指定烹饪区域的谓词 225 步内从未成立。这是部分条件被当作完整完成的误报。

任务 3 在第 245 步 abstain，理由涉及场景被重置/改变、看不到碗与可辨识抽屉。回放显示“碗在底层抽屉”首次成立于 138 步，“抽屉关闭”首次成立于 208 步，完整目标在 208–245 步持续成立；Agent 不具备环境重置权限。当前不可见不等于历史事件失效，部署未正确维护这一持续状态。

该案例还多次把“抬臂、后退、获得宽视角”等观察性指令交给冻结 VLA，验证器报告视角要求未实现。本部署没有独立验收过的相机移动技能，不能假设 VLA 能执行任意观察请求。任务 1 最终已成功，却因物体身份与历史推断冗长而触发 2048 token 上限，未正确确认结束。

两个关键任务的私有动作回放，其每一步完整成功标签与原记录一致。逐项谓词只用于离线诊断，未泄露到 Agent。对应研发对象是复合条件分解验证、带时效与可见性状态的事件记忆，以及具有明确能力合同的补充观察工具。

## 结论与适用边界

本轮两种适配 Agent 未提高总体最终成功数，也没有降低相对无 Agent 的 API 成本。有限动作预算内的少量成功改进与退化并存，不构成稳定排名。物理成功、Agent 是否认识成功、是否正确停止必须分别评价。

这是每任务单初态的开发诊断，不是多种子正式 benchmark、长短任务长度效应或 OOD 实验。单帧身份识别、策略的子任务提示分布变化、预算上限、部署工具缺失与长期状态错误相互交织，不能统一写成“长程记忆退化已被证明”。LIBERO 原生成功谓词也不必然包含独立松爪/稳定性约束，强视觉完成标准与谓词可能不同。

SAM3 依赖的 CaP-Agent0 默认路径、RPent 及本轮核查的 Zetta/OpenETA 相关分支按用户要求排除。Cortex 完整双系统仿真闭环未公开。未运行的方法没有填写成绩，也没有用通用 coding 框架替代机器人 Agent。
