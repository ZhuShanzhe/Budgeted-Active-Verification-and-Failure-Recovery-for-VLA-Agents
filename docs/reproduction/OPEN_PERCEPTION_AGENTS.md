# 新增机器人操作 Agent 测试记录

最新汇总：[长程时序能力测试 PDF](pdf/robotics_agent_long_horizon_report.pdf)，包含 Thea port、EmbodiedSkills 与本轮新增三套系统，按不同协议分别解释，不作为统一排名。

## 范围与命名

本轮在 LIBERO 机器人操作场景接入 RPent、Zetta 与 CaP-X / CaP-Agent0 单模型分支。使用公开可下载的感知资源，不使用受访问许可限制的 SAM3。Thea port 与 EmbodiedSkills 的既有结果保留在 `SAM3_FREE_LONG_RESULTS.md`，不改名为严格论文复现。

RPent 的十任务结果见 [RPent 结果](RPENT_OPEN_LONG_RESULTS.md)。Zetta 已从离线分析推进到冻结候选的真实在线配对恢复，见 [Zetta 结果](ZETTA_ONLINE_RESULTS.md)。CaP 的原生代码执行闭环见 [CaP 结果](CAPX_ONLINE_RESULTS.md)。接口修复与保留架构见 [运行适配记录](ROBOTICS_AGENT_RUNTIME_ADAPTATIONS.md)。OpenETA 不在本轮已测试范围。

通过安装、接口测试或代码单元测试不等于机器人性能；程序正常执行也不等于物理任务成功。以上为适配评测，各组工具、预算、任务和样本量不同，不构成统一排行榜。

## RPent 的保留项与替换项

保留官方 `ApiAgentLoop`、LIBERO Toolkit/Primitives、公开记忆、系统提示和原生动作工具：观察、目标分割、深度反投影、移动、旋转、抓取、释放与结束判断。公开记忆按轨迹复制，运行中只读；文件访问限制在该轨迹的公开目录。

替换 SAM3 为 Grounding DINO-base + SAM2.1-large；替换原策略服务为本项目已验证的 LeRobot Pi0.5 检查点；DeepSeek V4-Pro 组织调用，Flash 先转写图像。原环境后端换为现有 LIBERO-10。所有替换均属于适配评测。

任务真值只供宿主离线评分，不向 Agent 提供，也不自动成功停止。原代码的真值累积操作改为保留未知状态；局部抓取启发式的 `success` 仍然保留，不能把它当作完整任务完成。

这套部署比上一轮多用高清 RGB-D、相机标定、直接机械控制和公开记忆；VLA 每次执行 5 步。不能把成绩变化单独归因于 Agent 架构，也不能与上一轮双路 RGB、最长 32 步动作段的成绩混为严格公平排名。

### 接入检查

- 公开感知服务成功完成实际场景目标分割与有限三维位置返回。
- canary-v4 完成真实观察、分割、VLA 5 步动作、动作后状态保存；不计入成功率。
- api-smoke-v1 完成原生模型工具循环 3 轮，无接口错误；未执行物理动作，不计入成功率。
- 4 项本地边界测试通过：目标真值隔离、局部工具成功语义保留、嵌套屏蔽、两种掩码编码一致。
- 早期缺失依赖、未知终止值类型和工具状态捕获错误属于接入问题，不作为 Agent 失效证据。

### 任务协议

LIBERO-10 十任务；公开初态索引 40、种子 7、10 步预热、520 步物理上限。初态与稳定后状态哈希需和既有 Fixed 组一致。每轨迹最多 120 个规划轮、160 次模型调用、3 美元 API 预算，同时受批次剩余额度限制。决策输出最多 2048 token，图像转写 1536 token，思考模式关闭。

每任务一个初态是诊断性筛查，不是总体成功率或 OOD 泛化结论。报告最终成功、曾经成功、成功后丢失、完成误报、实际物理步数、API 次数与费用、原生工具时间线。失败原因必须回看实际图像和操作记录；不能从预算耗尽直接推出记忆失效。

## Zetta 的当前边界

原生协议、阶段、恢复控制、候选门控及 critic 状态测试共 84 项通过。其中 83 项在纯规划环境通过，1 项需要 robosuite 的资源路径检查在仿真依赖环境补测通过。它们是代码合同检查，不是机器人性能。

本轮离线实验复用已审核的 EmbodiedSkills 十任务轨迹，输入全部六条最终失败轨迹与按任务序确定的一条成功对照。保留 Zetta 原生 `review_clusters`、聚类提示、证据访问记录和证据/分组校验。仅提供匿名化证据 ID，不允许读取任意文件路径。API 调用代替原 Codex 持续会话；明确绑定图像字节哈希与证据 ID。保留原生图像历史裁剪，另做单因素图像保留上限诊断。

上述旧实验仍是只读的离线分析，不能追溯改名为在线成绩。新增在线实验另行采集固定 Pi0.5 的开发轨迹，在任务 5 的失败样本上生成并冻结 critic/恢复候选，然后在三个未用于本次规则生成的初态配对执行：控制组 2/3、候选 2/3，9 次真实恢复，没有救回失败轨迹。候选未晋升；尚未开展论文规模的完整演化与多任务门控。详见 `ZETTA_ONLINE_RESULTS.md`，开发数据与留出测试数据严格区分。
