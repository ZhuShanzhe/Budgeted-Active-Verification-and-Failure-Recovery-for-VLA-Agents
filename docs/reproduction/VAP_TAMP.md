## 可借鉴内容

项目沿用其“执行前验证—执行后验证—场景图更新”结构，把启发式多次查询替换为学习式成本感知路由，并将统一验证结果写入可追踪日志。

## 未达到运行复现的原因

完整系统依赖 ROS2、OmniGibson、Gemini API，以及 Segway/UR5e 等实体设备配置；当前单 GPU 服务器没有对应机器人与传感器。下载全部 LFS 资产仍不能补足硬件和在线 API 条件。

结论：作为系统接口和状态更新参考，不进入当前数值对比。
