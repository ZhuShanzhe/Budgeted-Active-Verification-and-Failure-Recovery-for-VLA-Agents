## 当前阶段的验收标准

已实现模块的验收要求是：真实环境可运行、输出可校验、标签不泄漏、根级不交叉、成本有来源、恢复起点一致、缺失信息可识别。规模不足、未标注、未配置 provider 和未进行闭环的项目均保留为未完成。

后续模型开发从固定输入契约、任务监督和轻量 critic 开始；路由学习及代码迭代使用相同接口。这里不以“流程跑通”代替论文创新、充分对照或统计有效性。
