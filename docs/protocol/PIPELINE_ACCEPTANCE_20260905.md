# 协议与采集管线验收

## 1. 结论

本轮已在服务器实现并测试程序化决策接口、固定预算执行器、根级数据划分、真实仿真采集、有限窗口恢复分支和代码迭代验收入口。研究范围仍为主动多模态证据获取、VLA 验证与失败恢复及跨分布泛化。

验收数据共 21 个 episode、13 个独立根、166 个动作后验证点。8 条轨迹达到目标，1 条在完整任务上限内失败，12 条为主动缩短的试跑，记作右删失而不是失败。它们是工程验收数据，不构成训练规模、正式 baseline 成绩或新方法提升。

## 2. 真实运行覆盖

| 验收内容 | 实际结果 |
|---|---|
| 自动检查 | 30 项通过：权限、预算、数据划分、标签隔离、扰动和拒绝式闸门 |
| OpenVLA-OFT 原始 LIBERO | 完整成功轨迹、训练/校准/开发根读取，以及受控扰动 |
| AVA-VLA | 4 个真实动作后验证点；跨策略特征接口可运行；短程结果右删失 |
| 原生 LIBERO-Plus | 七类各一个开发变体执行成功，合计 18 个验证点；不声称七类任务成功率 |
| 合成扰动 | 相机偏移、物体位移、动作噪声、延迟、遮挡和运动命令丢失 |
| 完整失败标签 | 动作命令丢失分支执行到 220 个任务步后超时；同根 clean 分支成功。属于受控故障，不冒充自然失败 |
| ManiSkill3 | 抓取、堆叠、侧向插孔三个官方动作回放成功，图像统一为 256×256，保存 RGB-D 和私有分割 |
| 完整性 | 文件哈希、物理步数、因果历史、证据状态不变、根级隔离检查通过 |
| 恢复重放 | 相机扰动后索引为 4 的决策点，三个分支均恢复到同一物理状态与同一 RGB；状态最大误差 0.0，像素最大误差 0 |
| 程序评测 | no-query 与 fixed-multiview 各执行 10 点，0 个错误；平均额外成本分别为 0 与 3 units |
| 代码变更闸门 | 正确拒绝缺少 critic、独立样本与 held-in 改善的候选，没有误报通过或部署 |

七类 Plus 变体为任务索引 0、258、608、984、1374、1725、2110，分别覆盖纹理、机器人初始状态、相机、语言、噪声、布局和光照。除语言变体外使用标准 BDDL 任务语言，避免文件后缀提示扰动类型。

恢复分支的 32 步窗口内均未观察到成功，不能据此称为不可恢复；也不能据此计算新方法恢复提升。“重新调用同一策略”在动作块边界是身份对照，不是高层规划器。

## 3. 没有伪造的字段与未完成部分

所有 166 点的语义失败层级和自然语言原因仍待构建。当前真实目标标签与完整轨迹结果可用；中间目标未满足不是失败原因标签。最早干预点仅能从已测试分支得到有限范围结论。

未配置主环境固定 critic，因此风险概率、Brier、证据价值和校准结果为空；no-query 与 fixed-multiview 只完成执行与扣费检查，没有检测性能排名。强 VLM、学习式分割、任务相关区域定位、物理移动相机和在线闭环恢复未实现，均未用替代值冒充。

当前可开始模型输入接口、轻量 critic 与路由器开发；正式训练需要扩大多任务采集并完善有来源的语义监督。本页初批验收时只有一个主训练原始状态根，不适合据此训练并报告泛化成绩；之后的 DROID 与多任务接续独立记录在 [数据准备接续](DATA_PREPARATION_CONTINUATION.md)，不回写为初批样本。

完整 coding 模型后端尚未接入，也没有发生模型自动改写和部署。候选程序解释、反馈包、固定评测与闸门均有可运行入口；最终测试仍未读取。

## 4. 实测修复与保留记录

- 首次 OFT 载入等待远端缓存查询，修正为现有本地缓存与离线加载；没有重复下载 7B 权重。

- ManiSkill3 早期默认图像尺寸试跑保留为旧记录；本验收使用统一 256×256 的 v2 数据。
- 将提前停止与完整失败区分，确保成功终止点被记录；持续动作干扰的恢复目前明确拒绝，避免分支中无意移除干扰。
- 旧 smoke、配置目录和失败日志保留，不覆盖原始数据，也不纳入正式成绩。
