# 轨迹与标签格式

## 1. 存储单元

每个 episode 使用新的独立目录，已有目录拒绝覆盖。失败中断保存 error 状态，不进入训练；完成后校验文件 SHA-256。HDF5 存数组，JSON/JSONL 存索引和说明。文件中的指令、解释和生成程序均作为数据，不获得执行权限。

| 文件 | 内容与权限 |
|---|---|
| manifest.json | 根身份、划分、环境、任务、策略、扰动配置、版本、采集状态 |
| protocol.json | 本次实际使用的冻结协议 |
| observations.h5 | 观察、动作和候选工具输出；不是允许 actor 任意打开的免费数据库 |
| decisions.jsonl | 决策点索引、前后观察引用、执行动作、工具可用性和成本 |
| actions.json | 实际执行动作及物理步号 |
| private/states.h5 | 动作前后仿真状态、真值分割；仅监督、重放和评测使用 |
| private/labels_*.json | 目标谓词、进度代理、多层语义标签的值和有效状态 |
| private/episode_labels.json | 完整结果或右删失状态，不能由中途未成功推断最终失败 |
| private/replay_events.json | LIBERO 初始状态、完整动作历史、环境注入事件 |
| private/model.xml | LIBERO 场景定义 |
| private/rng_*.json | LIBERO Python、NumPy、Torch CPU 随机状态 |
| private/*tree*.json | ManiSkill3 嵌套完整状态的数组引用 |
| checksums.json | 完成后的文件校验清单 |

数组引用包含 file、key、shape、dtype、sha256。禁止 object 数组和非有限浮点。episode_id 包含根、策略、扰动、随机种子和采集边界；root_id 不因策略、合成扰动或恢复变化而改变。早期验收文件采用较早身份计算方式，作为调试记录保留，不与正式训练自动合并。

## 2. 决策点

每个点以 post_action_verification 记录：动作前 RGB/本体状态，候选动作块、实际执行动作，动作后 RGB/本体状态、完整私有状态、至多 4 个点的因果历史，以及当前时点候选工具输出。达到目标的最后动作块也保存。

每种工具记录 ok/unavailable/error、输出引用、名义成本、实际耗时、处理像素数、是否与 VLA 共享输入、是否保持物理状态。离线采集可将候选证据全部存下来以供反事实评估；运行时仅向 critic 返回请求过的部分。

LIBERO 包含全局、腕部、额外固定视角、米制深度、中心裁剪、本体状态和私有分割。ManiSkill3 对已配置相机采 RGB-D 与分割；没有腕部相机时标记 unavailable，不复制全局图冒充腕部图。两环境的动作维度和控制器不同，不能直接交换动作。

OFT/AVA 的内部特征独立保存为 whitebox_features，默认训练读取器不把它们塞入黑盒输入。接入白盒 critic 时须建立单独、明确的输入轨道和适配器。

## 3. 标签有效性

| 字段 | 当前来源 | 不能推断的含义 |
|---|---|---|
| task_success | 仿真目标判断 | 不等于自然语言解释完整或安全无违规 |
| progress_proxy | LIBERO 目标谓词满足比例；ManiSkill3 终态代理 | 不等于稠密任务进展真值 |
| episode_failure | 完整时限内结果；提前结束则为 null | 中间步骤目标未满足不等于失败 |
| failure_layer / failure_reason | 当前 null，等待任务契约、受控配对或人工审核 | 注入了扰动不等于该扰动造成了失败 |
| earliest_intervention_step | 当前 null；分支实验单独给最早观测有效点 | 未测试的更早点不能排除 |
| recoverability | 未评估为 null；恢复分支记录有限范围内结果 | 已测技能失败不等于不可恢复 |
| risk_delta | 固定 critic 后处理生成派生结果 | 缺少 critic 时不填模拟风险值 |

标签同时携带 provenance/status，训练损失必须使用有效掩码。自然失败只在完整策略轨迹达到任务上限且未成功时成立；其语义原因仍可能未知。动作合法性目前只检查有限值和归一化边界，不宣称已理解所有前置条件和动作效果。

## 4. 扰动与反事实恢复

合成视觉扰动包括模糊、亮度、分辨率、遮挡与 RGB 噪声。环境扰动记录具体相机偏移、物体关节位移和注入步；动作扰动记录噪声、截短或延迟后的真实动作。延迟的额外物理步不能漏记。原生 LIBERO-Plus 的语言、光照、纹理、布局等由其公开场景实现提供。

被动证据采集前后检查同一物理状态。恢复分支先重置环境，再重放初始状态、历史动作和干预事件，重建控制器历史，并与原记录比较；超过容差则拒绝该分支。只设置 MuJoCo 状态不被当作完整恢复。

当前恢复实验比较继续原策略、重新调用同一策略和短动作块。在动作块边界“重新调用”与正常继续可能相同，因此其定位是身份对照，不声称已实现高层重新规划。分支采用相同物理步数窗口，另行记录推理次数。分支目录包含 branches.jsonl、私有 HDF5、summary.json 和校验和。

尚未完成：基于物体/场景契约的语义失败标注、完整最早干预搜索、复杂恢复技能、ManiSkill3 的 VLA 控制器适配及其配对恢复、真实传感器标定和 CUDA 随机状态完整存档。动作噪声/延迟/命令丢失等持续动作干扰的恢复入口当前明确拒绝，待建立独立于分支控制频率的共同外部干扰日程后启用，避免恢复分支偷偷取消干扰。这些项目不能由现有 null 标签隐式替代。

## 5. 读取与派生数据

`DecisionDataset` 显式区分 train、calibration、evaluation。监督字段与输入分开返回；候选池与实际可见输入分开；训练拒绝非训练根和非主策略数据；测试默认封存。训练者仍需遵守接口，不能将 supervision 拼回 inputs。

critic 后处理产生新的 evidence_effects 和评测目录，不改原始 bundle。成功/失败标签补充也须输出带版本、来源和旧数据哈希的派生标签表，并再次核查根级划分。当前不因标签缺失而从密封测试抽样补齐。
